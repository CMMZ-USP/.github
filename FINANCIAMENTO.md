# Registro de financiamento — CMMZ-USP

Registro central de todas as fontes de financiamento associadas à produção
desta organização. Cada linha corresponde a um topic aplicado aos
repositórios, o que permite listar automaticamente o que cada processo gerou.

## Como acrescentar um novo financiamento

1. Acrescente uma linha na tabela abaixo.
2. Defina o topic seguindo a convenção `<agencia>-<ano>-<numero>`
   (minúsculas; barras e pontos viram hífens).
3. Aplique o topic aos repositórios correspondentes
   (`gh repo edit CMMZ-USP/<repo> --add-topic <topic>`).
4. Acrescente o processo à seção **Financiamento** do README e ao
   `codemeta.json` de cada repositório envolvido.
