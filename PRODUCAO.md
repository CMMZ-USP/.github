# Produção científica e uso do CMMZ

Registro dos trabalhos que utilizaram o Centro de Museômica do MZUSP. Este
arquivo apoia os relatórios do processo FAPESP 2022/11560-6 (EMU), que exigem
demonstrar o uso multiusuário dos equipamentos.

**Usuários do centro:** para incluir seu trabalho, abra uma issue com o
modelo "Registrar produção que usou o CMMZ" ou envie um pull request
acrescentando uma linha nas tabelas abaixo.
